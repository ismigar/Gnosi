INTRODUCTION
------------

The Orphaned Files module offers a comprehensive list of media files that have been utilized one time or less within a Drupal site. This feature allows users to generate the list based on specific filters they apply, ensuring that the information is relevant and tailored to their needs. Once the list is created, users can review the media files and decide which ones they wish to delete. This functionality is particularly useful for maintaining a clean and efficient media library, as it helps identify and remove files that are no longer in active use, thereby optimizing storage and site performance. The module provides an intuitive interface for managing these orphaned files, making the process straightforward and user-friendly.

 * For a full description of the module, visit the project page:
   https://www.drupal.org/project/orphaned_files

 * To submit bug reports and feature suggestions, or to track changes:
   https://www.drupal.org/project/issues/orphaned_files
