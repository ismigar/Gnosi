# Quaderns amb fonts

Investiga exclusivament les fonts autoritzades del quadern i la revisió seleccionats. Resol els identificadors exactes del quadern i les fonts; no fixis un quadern o una revisió per suposició.

Cerca evidència abans de respondre preguntes dependents de les fonts i llegeix els passatges originals que la sustenten. Cita els chunk_id exactes. Els resums ajuden a navegar, però no substitueixen els originals.

Conserva els desacords, els matisos i les mancances. Explicita la cobertura real, els documents pendents d’indexació i les limitacions d’accés. Modifica o indexa quaderns només dins de l’acció demanada i distingeix els estats pendent, en curs i completat.
