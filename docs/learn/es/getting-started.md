# Instala Gnosi y da los primeros pasos

Crea un pequeño espacio de investigación, captura una idea y vuelve a encontrarla. Puedes completar este recorrido sin IA ni cuentas externas.

## Antes de empezar {#before-you-begin}

La aplicación de escritorio de tu sistema y una carpeta con permiso de escritura. En una instalación alojada, utiliza la dirección y cuenta facilitadas por su administrador.

## Pasos {#steps}

1. Descarga la versión para macOS, Windows o Linux desde [Descargas](https://gnosi.temenosismael.org/download/index.es.html). Sigue las instrucciones de instalación y seguridad de esa versión. La aplicación incluye su servidor; no necesitas instalar Python ni Node.

2. Abre Gnosi y elige el idioma en Configuración. En **Configuración → General → Archivos**, crea o selecciona un Vault. El Vault es la carpeta que contiene el conocimiento; comprueba su nombre antes de añadir contenido.

3. Para ver un ejemplo guiado, selecciona **Desde repositorio → Research Starter Workspace** en la configuración de Vaults. Crea uno nuevo y abre su nota inicial. La plantilla incluye ejemplos en castellano, catalán e inglés; en francés puedes seguir esta guía con un Vault vacío.

4. Crea una página llamada “Proyecto de lectura” y escribe una pregunta que quieras investigar. Sal de la página y vuelve a abrirla para comprobar que se ha guardado.

5. Crea una segunda página, inserta un enlace hacia ella desde la primera con el selector de páginas del editor y síguelo.

6. Cuando necesites funciones opcionales, abre Configuración → Complementos. Activa las que quieras para este Vault; su configuración aparecerá en el grupo correspondiente.

## Resultado esperado {#expected-result}

Tienes un Vault seleccionado, dos páginas guardadas y un enlace funcional. Después puedes añadir una fuente y una nota de lectura.

## Si algo falla {#troubleshooting}

Si falta una función, comprueba el Vault activo y sus complementos. Si la aplicación no abre la carpeta, revisa su ubicación y permisos antes de crear otra copia.
