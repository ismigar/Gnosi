# Ask questions about selected sources

A notebook groups selected reference records so that you can ask questions grounded in their attachments and URLs.

## Before you begin {#before-you-begin}

Enable Grounded Notebooks, configure a References table, and configure a compatible model for conversation. You need access to the source documents.

## Steps {#steps}

1. Create a notebook and select reference records whose attachment or URL fields contain the material you want to study.

2. Choose the notebook’s access mode deliberately. Private, collaborative and published modes have different audiences; published content is read-only for visitors.

3. Wait for the source panel to report successful ingestion. Inspect failed or stale sources rather than assuming every selected document was processed.

4. Ask a focused question such as “Which methods do these two sources use?” Open the answer’s citations and compare them with the source passages.

5. When a source changes, refresh it and check its status. You may continue seeing the last complete revision while a refresh runs.

6. Remove a resource from the notebook when it should no longer support answers. This removes notebook membership, not the original reference record.

## Expected result {#expected-result}

You receive an answer with citations to the material actually available in the notebook.

## If something goes wrong {#troubleshooting}

An empty notebook has no evidence to retrieve. Check attachments, accessible URLs and the configured model. Existing notebooks retain their original References table even if you change the default table later.
