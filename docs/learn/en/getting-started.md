# Install Gnosi and take your first steps

Create a small research workspace, capture an idea and find it again. You can complete this journey without AI or an external account.

## Before you begin {#before-you-begin}

The desktop app for your operating system and a folder you can write to. For a hosted installation, use the address and account provided by its administrator.

## Steps {#steps}

1. Download the matching macOS, Windows or Linux build from [Downloads](https://gnosi.temenosismael.org/download/). Follow the installation and security instructions for that release. The desktop app includes its backend; you do not need to install Python or Node.

2. Open Gnosi and choose your interface language in Settings. In **Settings → General → Files**, create or select a Vault. A Vault is the folder containing your knowledge; check its name before adding content.

3. For a guided example, choose **From repository → Research Starter Workspace** in the Vault settings. Create a new Vault and open its “Start here” note. The starter currently includes English, Catalan and Spanish examples; French users can follow this guide with an empty Vault.

4. Create a page called “Reading project” and write a short question you want to investigate. Leave the page and reopen it to check that your text was saved.

5. Create a second page, insert a link to it from the first page using the editor’s page-link picker, then follow that link.

6. Open Settings → Plugins when you need optional features. Activate only the features you want for this Vault; their settings then appear in the relevant group.

## Expected result {#expected-result}

You have a selected Vault, two saved pages and a working link. Next, add a source and a reading note.

## If something goes wrong {#troubleshooting}

If a feature is missing, check the active Vault and its enabled plugins. If the app cannot open your folder, check its location and write permissions before creating another copy.
