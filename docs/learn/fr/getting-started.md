# Installer Gnosi et faire ses premiers pas

Créez un petit espace de recherche, notez une idée et retrouvez-la. Vous pouvez suivre ce parcours sans IA ni compte externe.

## Avant de commencer {#before-you-begin}

L’application de bureau adaptée à votre système et un dossier accessible en écriture. Pour une installation hébergée, utilisez l’adresse et le compte fournis par son administrateur.

## Étapes {#steps}

1. Téléchargez la version macOS, Windows ou Linux depuis [Téléchargements](https://gnosi.temenosismael.org/download/). Suivez les consignes d’installation et de sécurité de cette version. Le serveur nécessaire est inclus ; inutile d’installer Python ou Node.

2. Ouvrez Gnosi et choisissez la langue dans les paramètres. Dans **Paramètres → Général → Fichiers**, créez ou sélectionnez un Vault. Le Vault est le dossier qui contient vos connaissances ; vérifiez son nom avant d’ajouter du contenu.

3. Pour découvrir un exemple guidé, choisissez **Depuis un dépôt → Research Starter Workspace** dans les paramètres des Vaults. Créez un nouveau Vault et ouvrez sa note de départ. Le modèle propose actuellement des exemples en anglais, catalan et espagnol ; vous pouvez suivre ce guide en français dans un Vault vide.

4. Créez une page « Projet de lecture » et écrivez une question à étudier. Quittez la page puis rouvrez-la pour vérifier son enregistrement.

5. Créez une seconde page, insérez un lien vers elle depuis la première avec le sélecteur de pages de l’éditeur, puis suivez ce lien.

6. Lorsque vous avez besoin de fonctions facultatives, ouvrez Paramètres → Extensions. Activez celles souhaitées pour ce Vault ; leurs réglages apparaîtront dans le groupe correspondant.

## Résultat attendu {#expected-result}

Vous disposez d’un Vault sélectionné, de deux pages enregistrées et d’un lien fonctionnel. Ajoutez ensuite une source et une note de lecture.

## En cas de problème {#troubleshooting}

Si une fonction manque, vérifiez le Vault actif et ses extensions. Si le dossier ne s’ouvre pas, contrôlez son emplacement et les droits d’écriture avant d’en créer une autre copie.
