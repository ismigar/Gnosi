# Interroger les sources sélectionnées

Un carnet regroupe des fiches bibliographiques pour répondre à des questions à partir de leurs pièces jointes et URL.

## Avant de commencer {#before-you-begin}

Activez les Carnets, configurez une table de références et un modèle compatible pour discuter. Vous devez avoir accès aux documents originaux.

## Étapes {#steps}

1. Créez un carnet et sélectionnez des fiches dont les champs de pièces jointes ou d’URL contiennent les documents.

2. Choisissez le mode d’accès avec attention. Privé, collaboratif et publié ont des publics différents ; les visiteurs d’un contenu publié ont un accès en lecture seule.

3. Attendez que le panneau des sources indique une ingestion réussie. Examinez les sources en échec ou périmées avant de les considérer comme traitées.

4. Posez une question précise, comme « Quelles méthodes ces deux sources utilisent-elles ? ». Ouvrez les citations et comparez-les aux passages originaux.

5. Lorsqu’une source change, actualisez-la et vérifiez son état. La dernière révision complète peut rester visible pendant l’actualisation.

6. Retirez une ressource du carnet si elle ne doit plus étayer les réponses. Cela retire son appartenance, sans supprimer la fiche originale.

## Résultat attendu {#expected-result}

Vous obtenez une réponse citant les documents effectivement disponibles dans le carnet.

## En cas de problème {#troubleshooting}

Un carnet vide ne contient aucune preuve à rechercher. Vérifiez pièces jointes, URL accessibles et modèle. Un carnet existant conserve sa table de références d’origine même si vous changez ensuite la table par défaut.
