# Preguntes freqüents i recuperació

Identifica el símptoma abans de canviar configuracions o copiar dades. Si has de comunicar una incidència, anota l’acció, el missatge i la versió de l’app.

## Abans de començar {#before-you-begin}

Accés a la instal·lació afectada. Abans de recuperar dades, conserva una còpia de l’estat actual i de la còpia de seguretat que vols restaurar.

## Passos {#steps}

1. **Falta una secció.** Comprova espai i Vault actius i verifica el complement a Configuració → Complements. Si no està fixada a la barra lateral, busca-la al llançador d’aplicacions.

2. **El model no respon.** Revisa agent, model, credencials i servei local. Si falten accions, comprova habilitats i suport d’eines; poder conversar no els garanteix.

3. **La importació és incompleta.** Revisa elements fallits, permisos i format. Reintenta una selecció petita després de comprovar duplicats; evita repetir tota la importació sense revisar-la.

4. **Un altre ordinador mostra dades diferents.** Comprova la carpeta del Vault a totes dues instal·lacions. Revisa el proveïdor de sincronització i reconnecta els comptes per dispositiu si cal. Les memòries cau i bases de dades de comptes no se sincronitzen automàticament amb el Markdown.

5. **Hi ha un conflicte de canvis.** Conserva el text pendent, recarrega la pàgina actual i compara les versions abans de desar.

6. **Cal recuperar dades.** Tanca Gnosi i pausa la sincronització. Conserva una còpia separada del Vault actual i del directori de dades de l’app. Restaura primer en una altra carpeta, selecciona aquell Vault i verifica pàgines i adjunts originals abans de substituir res. Les credencials i dades locals poden necessitar recuperació separada.

## Resultat esperat {#expected-result}

Has aïllat la funció que falla o verificat una còpia restaurada sense sobreescriure les úniques dades disponibles.

## Si alguna cosa falla {#troubleshooting}

**Cal IA?** No, el treball bàsic de coneixement funciona sense IA. **El Vault és una còpia completa?** Conté els fitxers de coneixement, però algunes dades locals i credencials viuen fora. Consulta la [guia de migració](https://github.com/ismigar/Gnosi/blob/main/docs/data-migration-3.md). **On comunico errors?** A [GitHub Issues](https://github.com/ismigar/Gnosi/issues), eliminant dades privades i credencials dels exemples.
