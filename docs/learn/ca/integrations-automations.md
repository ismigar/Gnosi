# Activa complements, connecta serveis i automatitza

Els complements habiliten funcions opcionals d’un Vault. Les integracions connecten comptes. Les automatitzacions executen operacions programades.

## Abans de començar {#before-you-begin}

Permís per canviar la configuració del Vault i un compte autoritzat per a accions externes. Activa Automatitzacions d’usuari per gestionar programacions.

## Passos {#steps}

1. Obre Configuració → Complements al Vault previst. Revisa la finalitat i els permisos del complement i activa’l. La seva configuració apareix al grup corresponent.

2. Afegeix una integració compatible i prova’n la connexió. Conserva les credencials a la configuració del compte, no en notes ni instruccions de xat.

3. Per importar de Notion, activa el complement, autoritza la font i comença amb una selecció petita. Revisa pàgines, taules i adjunts abans d’ampliar-la.

4. Obre Automatitzacions i configura operació, destinació i horari. Comença amb una tasca petita que no publiqui per poder-ne comprovar el resultat.

5. Activa-la i consulta l’historial després de l’execució. Verifica també el contingut real importat o actualitzat.

6. Pausa la tasca abans de canviar-ne el compte o la destinació. Revisa la configuració abans de reactivar-la.

## Resultat esperat {#expected-result}

La funció està disponible al Vault previst i la tasca programada té un resultat comprovable.

## Si alguna cosa falla {#troubleshooting}

Les programacions necessiten el servei de Gnosi en funcionament; l’app d’escriptori tancada no executa tasques locals. Desactivar un complement n’atura la funcionalitat: conservar-ne els comptes no significa que estigui actiu.
