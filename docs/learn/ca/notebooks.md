# Pregunta sobre les fonts seleccionades

Un quadern agrupa registres de referències per respondre preguntes basades en els seus adjunts i URL.

## Abans de començar {#before-you-begin}

Activa Quaderns, configura una taula de referències i un model compatible per conversar. Necessites accés als documents originals.

## Passos {#steps}

1. Crea un quadern i selecciona registres amb el material als camps d’adjunts o URL.

2. Tria el mode d’accés conscientment. Privat, col·laboratiu i publicat tenen audiències diferents; els visitants del contingut publicat només poden llegir-lo.

3. Espera que el panell de fonts indiqui una ingestió correcta. Revisa les fonts fallides o desactualitzades abans de donar-les per processades.

4. Fes una pregunta concreta, com “Quins mètodes utilitzen aquestes dues fonts?”. Obre les citacions de la resposta i compara-les amb els passatges originals.

5. Quan canviï una font, actualitza-la i comprova’n l’estat. Durant l’actualització encara pots veure l’última revisió completa.

6. Elimina un recurs del quadern si no ha de sustentar respostes. Això en treu la pertinença, no elimina el registre original.

## Resultat esperat {#expected-result}

Obtens una resposta amb citacions al material que el quadern té disponible.

## Si alguna cosa falla {#troubleshooting}

Un quadern buit no té evidències per recuperar. Revisa adjunts, URL accessibles i model. Els quaderns existents conserven la taula de referències original encara que després canviïs la taula predeterminada.
