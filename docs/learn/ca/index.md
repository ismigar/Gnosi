# Centre d’ajuda de Gnosi

Tria una guia per a la tasca que vols fer. Cerca pel nom d’una funció o amb una pregunta.

[Instal·la Gnosi i fes els primers passos](getting-started.md){ .md-button .md-button--primary }

## Comença aquí {#category-0}

<div class="grid cards" markdown>

- **[Instal·la Gnosi i fes els primers passos](getting-started.md)**

    Crea un petit espai de recerca, captura una idea i torna-la a trobar. Pots completar aquest recorregut sense IA ni cap compte extern.

- **[Espais de treball, Vaults i compartició](workspaces.md)**

    L’espai de treball determina amb qui treballes i amb quins permisos. El Vault conté els fitxers de coneixement. Canviar-ne un pot modificar els registres i la configuració visibles.

</div>

## Recerca i coneixement {#category-1}

<div class="grid cards" markdown>

- **[Crea pàgines, enllaços i adjunts](pages-files.md)**

    Utilitza pàgines per a les idees pròpies i conserva a prop el material que les sustenta. Gnosi desa el coneixement en fitxers Markdown i YAML.

- **[Organitza registres i planifica la feina](databases-planning.md)**

    Una base de dades agrupa taules. Una taula defineix propietats dels registres, que són pàgines; les vistes mostren els mateixos registres de maneres diferents.

- **[Explora enllaços i crea un genograma](graph-genograms.md)**

    El graf de coneixement mostra els enllaços entre materials. Un genograma representa persones i relacions familiars registrades explícitament.

- **[Captura fonts, llegeix i cita](reading-references.md)**

    Segueix el recorregut de recerca des de la font fins a l’evidència i l’escriptura pròpia. El lector de canals i la gestió bibliogràfica són funcions diferents.

- **[Pregunta sobre les fonts seleccionades](notebooks.md)**

    Un quadern agrupa registres de referències per respondre preguntes basades en els seus adjunts i URL.

- **[Configura un agent i un model](agents-models.md)**

    El model genera respostes. L’agent combina un model amb instruccions i habilitats; les eines li permeten executar accions concretes.

</div>

## Treball connectat {#category-2}

<div class="grid cards" markdown>

- **[Utilitza correu, calendari i contactes](mail-calendar-contacts.md)**

    Connecta els comptes necessaris i identifica quina font és propietària de cada missatge, esdeveniment o contacte.

- **[Prepara multimèdia i publica contingut](publishing-media.md)**

    El centre multimèdia conserva recursos reutilitzables. La publicació social prepara i envia contingut a les xarxes configurades.

- **[Activa complements, connecta serveis i automatitza](integrations-automations.md)**

    Els complements habiliten funcions opcionals d’un Vault. Les integracions connecten comptes. Les automatitzacions executen operacions programades.

</div>
