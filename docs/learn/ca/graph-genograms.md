# Explora enllaços i crea un genograma

El graf de coneixement mostra els enllaços entre materials. Un genograma representa persones i relacions familiars registrades explícitament.

## Abans de començar {#before-you-begin}

Dues pàgines enllaçades per al graf. Per al genograma, activa Genogrames i utilitza persones fictícies mentre aprens.

## Passos {#steps}

1. Obre Graf després d’enllaçar “Projecte de lectura” i “Notes de la font”. Cerca una pàgina, ajusta l’abast visible i obre un node per tornar al contingut.

2. Per crear el diagrama familiar, obre **Configuració → Complements → Genogrames**. Comprova el Vault de destinació i tria **Prepara les taules**. Es creen o reutilitzen Persones, Relacions i una vista de genograma.

3. Afegeix les persones fictícies “Àlex” i “Sam”. Deixa buides les dates desconegudes i indica només la precisió que coneguis.

4. A Relacions, selecciona els registres de les persones i el tipus de relació. Els noms no són identificadors: comprova la selecció si es repeteixen.

5. Obre la vista de genograma, tria la persona de referència i ajusta les generacions ascendents i descendents. La cerca ressalta noms; els filtres i les inclusions determinen la xarxa visible.

6. Revisa els avisos de validació. Completa les relacions en esborrany i corregeix els extrems invàlids abans de basar-te en el diagrama.

## Resultat esperat {#expected-result}

El graf obre les notes enllaçades i el genograma reflecteix les relacions familiars que has introduït.

## Si alguna cosa falla {#troubleshooting}

Es rebutgen els cicles de filiació i les autorelacions. Un familiar ocult pot quedar fora de l’abast seleccionat. Resol les relacions abans d’eliminar una persona referenciada; Gnosi no inventa vincles de substitució.
