Coneixement

Editor de blocs

Editor WYSIWYG estil Notion sobre Markdown estàndard: comandes slash, columnes, callouts i blocs embed (PDF, vídeo, web).

Bases de dades i vistes

Converteix carpetes en taules amb camps tipats (estat, relació, data, imatge, autoria...) i vistes taula, galeria, kanban, calendari i timeline.

Graf de coneixement

Visualitza wikilinks i etiquetes com un mapa interactiu (Sigma.js), amb suggeriments de connexió assistits per IA.

Markdown portable

Tot es desa com a fitxers Markdown que pots llegir, copiar i versionar amb qualsevol eina. Paperera amb soft-delete. Zero lock-in.

Investigació acadèmica

Gestor de referències

Motor de cites compatible amb Zotero (CSL/citeproc), importació per DOI/ISBN/arXiv/PMID, detecció de duplicats i bibliografies APA.

Lector PDF/EPUB

Visor de documents integrat (motor de Zotero). Els teus subratllats i anotacions es converteixen en cites reutilitzables.

Lector RSS

Subscripcions RSS/POP3 amb OPML jeràrquic, extracció full-text, favicons i un disseny net a tres columnes.

Comunicació i publicació

Correu i contactes

Client IMAP/SMTP amb push en temps real (IMAP IDLE) i OAuth de Google i Microsoft. Contactes integrats.

Calendari

Crea i edita esdeveniments a Google Calendar, amb autocompletat d'ubicació (OpenStreetMap), temps de desplaçament i convidats.

Xarxes i Drupal

Publica a Mastodon, Bluesky i Telegram amb ajuda d'IA, i sincronitza contingut amb Drupal en diversos idiomes.

Arxius i cerca

Media Center

Arxiu fotogràfic navegable amb miniatures (via QuickLook) per a vídeo i PDF, i gestor de múltiples arrels.

Multi-núvol

Cloud-agnòstic: OneDrive, iCloud, Google Drive o NextCloud. Adjunts portables i rutes configurables.

Cerca fiable

Índex d'arxius del vault al backend, independent del sincronitzador del núvol, amb suport de Spotlight.

Equip (opcional, en desenvolupament)

Comptes i workspaces Beta

Autenticació JWT, espais de treball i permisos per rol (propietari / admin / editor / lector). Desactivat en mode personal.

Col·laboració en temps real Aviat

Presència en viu sobre la pàgina; el canal està dissenyat per a edició col·laborativa (CRDT) a la fase següent.

Intel·ligència artificial, en els teus termes

Potent quan la vols, privada per defecte

🤖

Agent conversacional

Xateja amb el teu coneixement. Un agent amb LangGraph i eines via MCP que entén mencions @ a les teves pàgines, taules i bases de dades.

🔒

Local-first i multi-proveïdor

Executa models locals amb Ollama (gratis, privat) o connecta OpenAI, Claude, Groq, Gemini... Les teves claus, les teves dades, amb fallback automàtic.

🌐

Traducció integrada

Tradueix files, pàgines senceres o en massa amb Softcatalà, OPUS-MT local i DeepL. Detecció d'idioma i protecció d'acrònims.

Connexions semàntiques

Embeddings locals i memòria vectorial (ChromaDB) que suggereixen enllaços entre notes i enriqueixen el teu graf de coneixement.

Instal·la Gnosi

Tu decideixes on viu el teu coneixement

🏃

Self-host (natiu)

Recomanat

Gnosi és un backend FastAPI + un frontend Vite. S'executen directament, sense contenidors.

# 1 · Backend (FastAPI) $ git clone https://github.com/ismigar/Gnosi.git $ cd Gnosi/apps/gnosi $ python3 -m venv .venv && source .venv/bin/activate $ pip install -r requirements.txt $ uvicorn backend.server:app --port 5002 --reload # 2 · Frontend (en una altra terminal) $ cd Gnosi/apps/gnosi/frontend && npm install && npm run dev # 3 · Obre l'app → http://localhost:5173

Opcional: Ollama per a IA local. Guia completa al README.

🐳

Docker

Opcional

Prefereixes un sol comandament o desplegar en un servidor? Docker agrupa backend, frontend i el translation-server de Zotero.

$ cd Gnosi/apps/gnosi $ docker compose up -d --build → http://localhost:5173

Alternativa tot-en-un. No és necessària per fer servir Gnosi.

💻

App d'escriptori

Properament

Instal·ladors natius per a macOS, Windows i Linux (Tauri), amb el backend inclòs. Sense terminal, com Obsidian.

  • Un sol arxiu, doble clic i llest
  • Mode individual sense configuració
  • Publicat a GitHub Releases

En construcció. Segueix el repo per assabentar-te del llançament.
