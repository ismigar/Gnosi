Conocimiento

Editor de bloques

Editor WYSIWYG estilo Notion sobre Markdown: comandos slash, columnas, callouts y bloques embed (PDF, vídeo, web).

Bases de datos y vistas

Campos tipados (estado, relación, fecha, imagen, autoría...) y vistas tabla, galería, kanban, calendario y timeline.

Grafo de conocimiento

Visualiza wikilinks y etiquetas como un mapa interactivo (Sigma.js), con conexiones semánticas asistidas por IA.

Markdown portable

Ficheros Markdown que puedes leer y versionar con cualquier herramienta. Papelera con soft-delete. Cero lock-in.

Investigación académica

Gestor de referencias

Motor de citas compatible con Zotero (CSL/citeproc), importación por DOI/ISBN/arXiv/PMID y bibliografías APA.

Lector PDF/EPUB

Visor integrado (motor de Zotero); tus subrayados y anotaciones se convierten en citas reutilizables.

Lector RSS

Suscripciones RSS/POP3 con OPML jerárquico, extracción full-text, favicons y diseño limpio a tres columnas.

Comunicación

Correo

Cliente IMAP/SMTP con push en tiempo real (IMAP IDLE) y OAuth de Google y Microsoft.

Calendario

Eventos en Google Calendar con autocompletado de ubicación (OpenStreetMap), tiempo de desplazamiento e invitados.

Contactos

Libreta de direcciones integrada con el correo y el calendario.

Publicación y traducción

Redes sociales

Publica y programa en Mastodon, Bluesky y Telegram, con propuestas generadas por IA que respetan cada red.

Sincronización con Drupal

Publica notas y tablas en tu web Drupal, en varios idiomas, con imágenes optimizadas y PDFs comprimidos.

Traducción automática

Traduce registros y páginas enteras (Softcatalà, OPUS-MT local, DeepL) con detección de idioma y protección de acrónimos.

Add-in Word y LibreOffice

Inserta y gestiona citas desde Microsoft Word (Office Add-in) y LibreOffice Writer con la extensión «Gnosi Cite».

Archivos y búsqueda

Media Center

Archivo fotográfico navegable con miniaturas (vía QuickLook) para vídeo y PDF, y gestor de múltiples raíces.

Multi-nube

Cloud-agnóstico: OneDrive, iCloud, Google Drive o NextCloud. Adjuntos portables y rutas configurables.

Búsqueda fiable

Índice de archivos del vault en el backend, independiente del sincronizador de la nube, con apoyo de Spotlight.

Equipo (opcional, en desarrollo)

Cuentas y workspaces Beta

Autenticación JWT, espacios de trabajo y permisos por rol (propietario / admin / editor / lector). Desactivado en modo personal.

Colaboración en tiempo real Pronto

Presencia en vivo sobre la página; el canal está diseñado para edición colaborativa (CRDT) en la siguiente fase.

Inteligencia artificial, en tus términos

Self-host (nativo)

Recomendado

Gnosi es un backend FastAPI + un frontend Vite. Se ejecutan directamente, sin contenedores.

# 1 · Backend (FastAPI) $ git clone https://github.com/ismigar/Gnosi.git $ cd Gnosi/apps/gnosi $ python3 -m venv .venv && source .venv/bin/activate $ pip install -r requirements.txt $ uvicorn backend.server:app --port 5002 --reload # 2 · Frontend (en otra terminal) $ cd Gnosi/apps/gnosi/frontend && npm install && npm run dev # 3 · Abre la app → http://localhost:5173

Opcional: Ollama para IA local. Guía completa en el README.

🐳

Docker

Opcional

¿Prefieres un solo comando o desplegar en un servidor? Docker agrupa backend, frontend y el translation-server de Zotero.

$ cd Gnosi/apps/gnosi $ docker compose up -d --build → http://localhost:5173

Alternativa todo-en-uno. No es necesaria para usar Gnosi.

💻

App de escritorio

Disponible · beta

Instaladores nativos para macOS, Windows y Linux (Electron), con el backend incluido. Sin terminal, como Obsidian.

  • Un solo archivo, doble clic y listo
  • Modo individual sin configuración
  • Descárgalo de GitHub Releases

Beta; binarios sin firmar (en macOS: clic derecho → Abrir). Descargas.

📲

App web (PWA)

Disponible

Instala Gnosi como aplicación desde el navegador, con su propia ventana e icono.

  • Chrome/Edge: «Instalar»
  • Safari: «Añadir al Dock»
  • Sobre tu instancia self-host o local

Requiere una instancia de Gnosi en marcha (self-host o desarrollo local).
