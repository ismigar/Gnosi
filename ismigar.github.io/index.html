Conocimiento

Editor de bloques

Editor WYSIWYG estilo Notion sobre Markdown estándar: comandos slash, columnas, callouts y bloques embed (PDF, vídeo, web).

Bases de datos y vistas

Convierte carpetas en tablas con campos tipados (estado, relación, fecha, imagen, autoría...) y vistas tabla, galería, kanban, calendario y timeline.

Grafo de conocimiento

Visualiza wikilinks y etiquetas como un mapa interactivo (Sigma.js), con sugerencias de conexión asistidas por IA.

Markdown portable

Todo se guarda como ficheros Markdown que puedes leer, copiar y versionar con cualquier herramienta. Papelera con soft-delete. Cero lock-in.

Investigación académica

Gestor de referencias

Motor de citas compatible con Zotero (CSL/citeproc), importación por DOI/ISBN/arXiv/PMID, detección de duplicados y bibliografías APA.

Lector PDF/EPUB

Visor de documentos integrado (motor de Zotero). Tus subrayados y anotaciones se convierten en citas reutilizables.

Lector RSS

Suscripciones RSS/POP3 con OPML jerárquico, extracción full-text, favicons y un diseño limpio a tres columnas.

Comunicación y publicación

Correo y contactos

Cliente IMAP/SMTP con push en tiempo real (IMAP IDLE) y OAuth de Google y Microsoft. Contactos integrados.

Calendario

Crea y edita eventos en Google Calendar, con autocompletado de ubicación (OpenStreetMap), tiempo de desplazamiento e invitados.

Redes y Drupal

Publica en Mastodon, Bluesky y Telegram con ayuda de IA, y sincroniza contenido con Drupal en varios idiomas.

Archivos y búsqueda

Media Center

Archivo fotográfico navegable con miniaturas (vía QuickLook) para vídeo y PDF, y gestor de múltiples raíces.

Multi-nube

Cloud-agnóstico: OneDrive, iCloud, Google Drive o NextCloud. Adjuntos portables y rutas configurables.

Búsqueda fiable

Índice de archivos del vault en el backend, independiente del sincronizador de la nube, con apoyo de Spotlight.

Equipo (opcional, en desarrollo)

Cuentas y workspaces Beta

Autenticación JWT, espacios de trabajo y permisos por rol (propietario / admin / editor / lector). Desactivado en modo personal.

Colaboración en tiempo real Pronto

Presencia en vivo sobre la página; el canal está diseñado para edición colaborativa (CRDT) en la siguiente fase.

Inteligencia artificial, en tus términos

Agente conversacional

Chatea con tu conocimiento. Un agente con LangGraph y herramientas vía MCP que entiende menciones @ a tus páginas, tablas y bases de datos.

Local-first y multi-proveedor

Ejecuta modelos locales con Ollama (gratis, privado) o conecta OpenAI, Claude, Groq, Gemini... Tus claves, tus datos, con fallback automático.

🌐

Traducción integrada

Traduce filas, páginas enteras o en masa con Softcatalà, OPUS-MT local y DeepL. Detección de idioma y protección de acrónimos.

Conexiones semánticas

Embeddings locales y memoria vectorial (ChromaDB) que sugieren enlaces entre notas y enriquecen tu grafo de conocimiento.

Self-host (nativo)

Recomendado

Gnosi es un backend FastAPI + un frontend Vite. Se ejecutan directamente, sin contenedores.

# 1 · Backend (FastAPI) $ git clone https://github.com/ismigar/Gnosi.git $ cd Gnosi/apps/gnosi $ python3 -m venv .venv && source .venv/bin/activate $ pip install -r requirements.txt $ uvicorn backend.server:app --port 5002 --reload # 2 · Frontend (en otra terminal) $ cd Gnosi/apps/gnosi/frontend && npm install && npm run dev # 3 · Abre la app → http://localhost:5173

Opcional: Ollama para IA local. Guía completa en el README.

🐳

Docker

Opcional

¿Prefieres un solo comando o desplegar en un servidor? Docker agrupa backend, frontend y el translation-server de Zotero.

$ cd Gnosi/apps/gnosi $ docker compose up -d --build → http://localhost:5173

Alternativa todo-en-uno. No es necesaria para usar Gnosi.
